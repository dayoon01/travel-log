# 여행 기록

사진의 촬영 위치·시각(EXIF)을 따라 지도와 글이 함께 움직이는 여행기 페이지를 만든다.

## 새 여행 추가

1. `trips/<여행이름>/photos/`에 사진·영상을 넣는다. 폴더 이름은 영문을 권장한다(예: `jeju-2026-11`).
2. 위치·시각을 읽고 지점을 묶는다.
   ```
   python tools/extract.py trips/<여행이름>
   ```
   `trip.json` 뼈대가 생긴다.
3. Claude Code에게 "이 여행 글 써줘"라고 요청한다. 사진을 보고 `trip.json`의 제목·본문·캡션을 채운다.
4. 페이지를 만든다.
   ```
   python tools/build.py
   ```
5. `dist/` 폴더가 완성본이다. 인터넷에 올리려면 다음 명령을 실행한다.
   ```
   python tools/deploy.py
   ```
   다시 빌드한 뒤 `gh-pages` 브랜치로 올린다. 1~2분 뒤 https://dayoon01.github.io/travel-log/ 에 반영된다.
   원본 사진(`trips/*/photos/`)은 저장소에 올라가지 않는다. 다른 PC에서 다시 빌드하려면 사진 폴더를 따로 옮겨야 한다.

## 알아 둘 점

- `dist/`에 들어가는 사진은 EXIF(위치·기기 정보)를 지운 사본이다. 다만 페이지의 지도에는 촬영 지점이 표시되므로, 집 주변 사진은 빼고 올린다.
- 아이폰 HEIC 사진은 JPG로 바꿔서 넣는다. 아이폰 설정 → 카메라 → 포맷에서 '높은 호환성'을 고르면 처음부터 JPG로 찍힌다.
- 영상은 위치 정보를 읽지 못한다. 그래서 30분 안에 찍은 사진 중 시각이 가장 가까운 사진의 위치를 빌려 쓴다.
- 지점 묶음 기준은 `tools/extract.py`의 `GAP_MIN`(60분)과 `RADIUS_M`(400m)이다.
- 지점별 지도 확대 수준을 바꾸려면 `trip.json`의 해당 지점에 `"z": 15`처럼 적는다. 위치를 직접 지정하려면 `"c": [위도, 경도]`를 적는다.
- `trips/kyoto-osaka-2026`은 `tools/make_samples.py`로 만든 예시다. 사진은 가짜이고, 글도 실제 여행 기록이 아니다.
